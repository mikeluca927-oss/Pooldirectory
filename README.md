# Monmouth Pool Permit Leads

Homes in Monmouth County, NJ with an in-ground pool permit issued since January 2025, confirmed against each town's own permit record.

- `index.html` is the lead tracker. Open it in a browser. It filters by town, stage and permit date, and copies the list as CSV.
- `leads.csv` is the same 80 properties as a spreadsheet.

## Coverage

Wall Twp (58), Marlboro (14) and Asbury Park (8). These are the towns whose permit descriptions could be checked online. Other Monmouth towns are not included.

## Sources

- Permits: NJ DCA construction permit feed on data.nj.gov, through October 6, 2026.
- Pool confirmation and stage: town permit records on SDL Portal, checked November 17, 2026.
- Addresses and assessed values: NJ statewide parcel records. Owner names are withheld from that file.

This is a snapshot. It does not refresh on its own.
